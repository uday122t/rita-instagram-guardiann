# RITA Instagram Guardian

لوحة أولية لمساعدة مشرف المجموعة على تنظيم المراجعة وتسجيل المخالفات.

## الحالة الحالية
- واجهة لوحة تحكم عربية.
- تسجيل مخالفات يدويًا وإدارة قواعد محلية داخل المتصفح.
- نقطة فحص للخادم عبر `/api/health`.
- لا يوجد اتصال فعلي بإنستغرام في هذه النسخة.

## حدود Instagram
واجهات Meta الرسمية لا تمنح هذا المشروع تلقائيًا صلاحية قراءة وإدارة كل محادثات المجموعات أو حذف رسائل الآخرين أو طرد أعضاء مجموعات Instagram. لذلك لا ندّعي تنفيذ هذه الإجراءات. أي تكامل مستقبلي يجب أن يستخدم OAuth وواجهات Meta الرسمية والصلاحيات المعتمدة فقط.

## التشغيل محليًا
```bash
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\\Scripts\\activate
pip install -r requirements.txt
uvicorn main:app --reload
```
ثم افتح http://127.0.0.1:8000

## الأسرار
انسخ `.env.example` إلى `.env` عند إضافة تكامل رسمي. لا تضع كلمات مرور Instagram أو رموز الوصول في GitHub.

## النشر
يمكن نشر التطبيق على Replit أو خدمة تدعم Python باستخدام:
`uvicorn main:app --host 0.0.0.0 --port 8000`
